# Educational Policy Analysis & Program Evaluation

Decision analysis, logic models, and program evaluation — Bardach's eightfold path, CIPP/Kirkpatrick, cost-benefit analysis, and equity impact — with an interactive logic-model builder and options scorer.

## ▶ Live demo

**https://freddricklogan.github.io/educational-policy-analysis/**

A single, self-contained interactive resource — open the live demo above, or open `index.html` locally in any browser (no build step, no dependencies).
